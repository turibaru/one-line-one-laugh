# One Line, One Laugh

One joke, one line, one laugh — an entry for the make.fun bounty "One Line, One Laugh". The whole entry is a single self-contained line; the runner in `main.ts` just carries it to the output folder.

Our line:

> The hotel minibar charged me $18 for a cashew, so I left it a one-star review and it charged me $18 for that too.

The minibar charges $18 for a single cashew, so I hit back with a one-star review — and the minibar bills me another $18 for the review itself. The sting is the second $18: complaining about the price costs exactly as much as the thing I was complaining about.
